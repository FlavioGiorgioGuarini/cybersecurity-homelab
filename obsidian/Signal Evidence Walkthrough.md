# Signal Evidence Walkthrough

Duplicate this note to document a defensive analysis. Record whether the inputs were a built-in synthetic sample or approved local data. Use fictional records in public examples.

| Item | Evidence to record |
| --- | --- |
| Scenario | Lab ID, source revision, input type and analyst question |
| Observations | Case field or event and its observable value |
| Interpretation | What the observations support and what remains uncertain |
| Decision | Defensive response with a reason tied to the evidence |
| Alternative | What would change the decision |
| Verification | Sample runner, local report command or workspace export used |

The scenario and known decision behavior live in `docs/labs.mjs`. See [[Signal Workspace Operations]] for ingestion and export, [[Signal Workspace QA]] for browser checks and [[Signal Lab Authoring]] for changes to a case.
